# Why

Use a cloud provider's accumulated technology, architectural and industry expertise to make software production increasingly efficient, so that more software can be built, modernized and operated on its platform with fewer resources. Cloud experts encode their knowledge in blueprints which are compiled into complete systems; and developers begin innovating from Sprint 1 rather than building the foundation from scratch.

## The Transformation Creates Four Transcendent Benefits

The four layers are not sequential benefits where one is inherently more valuable than another. They represent four equal ways the transformation can create strategic advantage.

---

## 1. Production Power

### Make Software Cheaper to Produce

*The Engine That Turns Cloud Knowledge into Systems*

The cloud provider's technology and architectural knowledge becomes executable through blueprints, models and system generation.

---

## 2. Intellectual Capital

### Turn Cloud Expertise Into Assets

*What We Know. What We Can Encode.*

The cloud provider's technology, solution and industry expertise becomes reusable software-production IP that can be applied across its ecosystem.

---

## 3. Compounding Advantage

### Make Every Application Expand Cloud Consumption

*More Software. More Workloads. More Resources.*

As software becomes less expensive to produce, more applications can be created, modernized and re-platformed. The resulting workloads create additional demand for cloud resources across the ecosystem.

---

## 4. Production Intelligence

### Turn Accumulated Knowledge Into AI Capability

*The Moat That Learns and Accelerates*

The structured body of production knowledge becomes an increasingly powerful substrate for AI to understand, extend, improve and ultimately operate software production.

---

# Four Benefits. One Transformation.

**The cloud provider decides which matters most.**

- Lower the resources required to produce software.
- Turn cloud expertise into proprietary production IP.
- Expand software production and the resulting consumption of cloud resources.
- Create an increasingly AI-operable software-production capability.
