## H02-02 — A Blueprint Continuum Can Cover Increasing Classes of Systems

> **Hypothesis:** A sufficiently broad collection of technology, solution and industry blueprints can address an increasing percentage of software systems built on the cloud.

### Summary

Allow blueprints to exist at different levels of abstraction and to be extended or derived for increasingly specific applications.

### Implementation

Technology Blueprint → Solution Blueprint → Industry Blueprint → Customer Extension → Generated System.

### Value — Today

Existing blueprints address defined classes of applications and technologies.

### Value — Tomorrow

An expanding continuum of blueprints reduces the amount of software production that must begin from an empty project.

### Evidence

[Blueprints](../../evidence/blueprints/README.md); [Industry Domain Models](../../evidence/domain-models/README.md)

### Vision

The starting point for software production increasingly becomes an applicable blueprint rather than a blank repository.
