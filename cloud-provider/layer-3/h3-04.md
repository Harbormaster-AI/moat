## H3-04 — Lower Production Cost Expands Software Creation

> **Hypothesis:** When software can be produced with substantially less effort, organizations can economically undertake more software creation, modernization and replacement.

### Summary

Reduce the production effort required for systems through reusable blueprints, allowing existing resources to produce additional software capability.

### Implementation

Blueprint Coverage ↑ → Production Effort ↓ → Available Capacity ↑ → Software Production ↑.

### Value — Today

Reduced production effort can be applied to existing software projects.

### Value — Tomorrow

Released capacity can support additional application development, modernization and re-platforming.

### Evidence

[Production Measurements](../../evidence/measurements/README.md); [Generated Systems](../../evidence/generated-systems/README.md)

### Vision

Lower software-production cost expands the amount of software organizations can economically create.
