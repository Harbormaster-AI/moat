# History
The following represent proof points 2 major corporations, looking to adopt the system to create 
global leverage at scale.

## Strategic Acquisition Consideration @ Fortune 20
__Event Intent__:  
Strategic Acquisition

__Purpose__:  
Provide technology to lift enterprise application migration program  

__Overview__:  
May 2017 - Engaged Senior Manager via email  
May 2017 - Demonstrated platform to Senior Developer  
May 2017 - Met with General Manager
May-Sept 2017 - Multiple meetings and demonstrations  
Sept 2017 - Technology acceptance with handover for business due diligence

__Result__:  
Met technology due diligence.  However, the intended acquirer was unable to discover an enterprise engagement with their professional services.  Momentum and interest stalled. 

## Proof of Concept @ Fortune 50
__Event Intent__:  
Leverage Automation to Execute a Global Microservice Strategy

Purpose:  
Use a blueprint model driven system to compile into ready to use microservice ecosystems.

Overview:
- Enterprise Architecture created a large reference implementation related to building a microservice based system. 
- The system was deemed too complicated to use by teams to turn into the system they needed.
- Harbormaster engaged
- The core of the reference implementation was turned into a reusable blueprint
- Use an  OpenAPI contract as the domain model
- Compiled blueprint and domain model in an entire microservice ecosystem was created with automatic integration into their Enterprise Jenkins deployment  
-- Front microservices with Spring Boot controller  
-- Back microservices with a persistent event source  
-- Fully instrumented for options : database engine type, telemetry, logging, etc..

Result:
- Teams who were once unwilling to adopt the Enterprise strategy, adopted the new strategy
- Other teams looked to transform other reference implementations into blueprints
- Adoption ensued as EA had hoped
