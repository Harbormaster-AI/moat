## H1-02 — Generation Can Produce Production-Ready Systems

> **Hypothesis:** A software-production platform can generate systems that contain sufficient application, infrastructure and deployment configuration to move directly into deployment and operation.

### Summary

Generate more than application source code. A production model can be compiled into a complete system including application structure, infrastructure configuration, deployment artifacts and operational configuration.

### Implementation

Model → Blueprint → System Configuration → Application + Infrastructure + Deployment Artifacts → Deploy.

### Value — Today

Generated systems can provide a repeatable starting point for deployment into managed private, hybrid or public-cloud environments.

### Value — Tomorrow

Increasing portions of the production and deployment environment can be generated consistently as part of the system itself.

### Evidence

[Generated Systems](../../evidence/generated-systems/README.md); [Infrastructure](../../evidence/infrastructure); 

### Vision

The boundary between software production and infrastructure provisioning becomes increasingly automated and repeatable.
