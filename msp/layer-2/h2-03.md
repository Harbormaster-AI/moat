## H2-03 — Infrastructure and Cloud Knowledge Can Be Encoded

> **Hypothesis:** Knowledge about infrastructure, cloud, deployment and operational environments can be represented as executable production configuration.

### Summary

Extend production knowledge beyond application code to include infrastructure and deployment configuration, allowing system production to encompass the environment required to run the resulting workload.

### Implementation

Application Model + Infrastructure Knowledge + Cloud Configuration → Infrastructure-as-Code + Deployment Configuration → Running Workload.

### Value — Today

Infrastructure and deployment patterns can be standardized and reused across supported environments.

### Value — Tomorrow

A broader range of private, hybrid and public-cloud environments can be represented as reusable production capability.

### Evidence

[Infrastructure](../../evidence/infrastructure); [Cloud Configurations](../../evidence/cloud-configurations); 

### Vision

Application production and infrastructure provisioning increasingly become one coordinated production process.
